| Database as Code | Open `db/schema.sql` and `db/data.sql`. Show that the schema and seed are versioned. | `Get-Content .\\db\\schema.sql -TotalCount 80`; `Get-Content .\\db\\data.sql -TotalCount 80` | The authoritative relational model is in `db/`, even though some services still use mixed Hibernate DDL behavior locally. |
